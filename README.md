# 방 만들기

이사 전에 가구 배치를 직접 해 보고, 사기 전에 방에 들어가는지 확인하는 웹사이트입니다.

- **배치 도구** — 방 크기(cm)를 넣고 가구를 끌어다 놓습니다. 겹치거나 방 밖으로 나가면 색으로 알려 줍니다.
- **자동 배치** — 넣은 가구를 규칙(벽에 붙이기, 문 앞 통로 비우기, 책상은 창문 쪽 등)에 따라 알아서 놓습니다. AI 없이 브라우저 안에서 계산합니다.
- **사진·링크로 가구 불러오기** — 가구 사진을 올리고 「AI로 읽기」를 누르면 AI(OpenAI)가 사진에 적힌 치수를 읽어 확인 표를 채웁니다. 사람이 사진과 비교해 확인한 뒤 방에 넣습니다. 상품 링크는 아직 AI가 읽지 못해 직접 적습니다.
- **AI 렌더** — 지금 배치한 도면(과 선택한 방 사진)으로 AI(OpenAI)가 분위기 이미지 1장을 바로 만듭니다. 한 브라우저당 처음 2회 무료이고, 그 뒤 유료 이용은 준비 중입니다(결제 없음, 구글 폼으로 알림 신청만 받음).

> 시범 운영 중인 프로젝트입니다. 가구 치수는 흔한 예시 값이라 실제 제품 치수로 바꿔 쓰세요.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 첫 화면 |
| `배치.html` | 배치 도구 |
| `렌더신청.html` | AI 렌더 안내와 신청 |
| `공통.css` | 공통 디자인 (색은 맨 위 `:root`) |
| `설정.js` | 구글 폼 주소, 렌더 가격 후보, 가구 치수 등 **바꿔 쓰는 값** |
| `api/read-furniture.js` | 사진에서 가구 치수를 읽는 서버 함수 (Vercel에서 자동으로 서버 함수가 됨) |
| `api/render.js` | 도면(+방 사진)으로 AI 렌더 이미지를 만드는 서버 함수 |
| `tests/` | 가짜 AI로 하는 자동 시험 (`npm test`) |
| `서버.js` · `사이트_열기.bat` | 내 컴퓨터에서 열어 보는 작은 서버 |
| `사용법.md` | 설정 방법 안내 |

외부 라이브러리 없이 HTML · CSS · JavaScript만으로 만들었습니다. 글꼴은 [Pretendard](https://github.com/orioncactus/pretendard)와 [Jua](https://fonts.google.com/specimen/Jua)(둘 다 SIL OFL)를 인터넷에서 불러옵니다.

## 내 컴퓨터에서 열기

[Node.js](https://nodejs.org)가 설치되어 있으면:

```powershell
node 서버.js --open
```

Windows에서는 `사이트_열기.bat`을 더블클릭해도 됩니다. 주소는 `http://localhost:8080`입니다.

## 개인정보

- 배치 작업은 쓰는 기기의 브라우저에만 저장됩니다.
- 「가구 불러오기」에 올린 사진은 기본적으로 이 기기 안에서만 쓰입니다. **「AI로 읽기」를 누른 사진만** 서버를 거쳐 OpenAI로 전송되어 치수를 읽는 데 쓰이고, 이 서버에는 저장하지 않습니다.
- AI 키(`OPENAI_API_KEY`)는 서버의 환경 변수에만 두고, 코드와 저장소에는 넣지 않습니다. 설정 방법은 `사용법.md`의 6장을 보세요.
- AI 렌더에 쓴 도면과 방 사진도 이 서버에는 저장하지 않고, 만드는 동안만 OpenAI로 보냅니다.
- 유료 이용 알림 신청 정보는 구글 폼으로 받습니다. 폼 주소는 `설정.js`에서 연결합니다.
